How to Generate Excel Files from Database Objects Using ZetExcel in C#

Create and format Excel reports from SQL Server queries, DataTables, and Entity Framework results without requiring Microsoft Excel on the server.

July 15, 2025

Generating Excel reports is a common requirement in enterprise applications, from employee and attendance reports to loan statements, CRM reports, and financial dashboards. Microsoft Office Interop can make deployment difficult because it requires Excel to be installed on the server. ZetExcel provides a way to create, format, and export Excel files directly from .NET applications without that dependency.

This guide covers creating workbooks, formatting cells, importing data from SQL Server, exporting DataTables and Entity Framework results, and organizing reusable export logic.

Why use ZetExcel?

  • Generate Excel files without installing Microsoft Excel.
  • Create XLSX reports programmatically and apply formatting.
  • Import data from DataTables and collections.
  • Use it in .NET Framework, .NET Core, and ASP.NET applications.

Create a simple Excel file

Create a workbook, get its first worksheet, populate cells, and save the workbook:

Workbook workbook = new Workbook();
Worksheet sheet = workbook.Worksheets[0];
sheet.Cells["A1"].Value = "Employee";
sheet.Cells["B1"].Value = "Salary";
sheet.Cells["A2"].Value = "Suresh";
sheet.Cells["B2"].Value = 125000.50;
workbook.Save("Employees.xlsx");

This creates a spreadsheet with employee and salary values.

Format text and headers

Create a style and apply it to the header cells to make the column names stand out:

Style headerStyle = workbook.CreateStyle();
headerStyle.Font.Bold = true;
headerStyle.Font.Size = 12;
headerStyle.Fill.ForegroundColor = Color.LightBlue;
sheet.Cells["A1"].Style = headerStyle;
sheet.Cells["B1"].Style = headerStyle;

Other common text formatting options include bold and italic text, font size and font name, and horizontal alignment:

style.Font.Bold = true;
style.Font.Italic = true;
style.Font.Size = 14;
style.Font.Name = "Calibri";
style.Alignment.Horizontal = HorizontalAlignment.Center;

Format numbers and dates

Number formats make values easier to read. For example, assign a currency format to a salary cell:

Style currencyStyle = workbook.CreateStyle();
currencyStyle.NumberFormat = "₹#,##0.00";
sheet.Cells["B2"].Style = currencyStyle;

This displays a value such as 125000.50 as ₹125,000.50. Other useful number formats include #,##0.00 for decimals, 0.00% for percentages, and dd-MMM-yyyy for dates.

Export data directly from SQL Server

Fetch query results into a DataTable using a SQL connection and adapter:

SqlConnection conn = new SqlConnection(connectionString);
SqlDataAdapter da = new SqlDataAdapter(
    "SELECT EmployeeName, Salary, JoiningDate FROM Employee",
    conn);
DataTable dt = new DataTable();
da.Fill(dt);

Import the DataTable into the worksheet with its column names as headers, then save the workbook:

Workbook workbook = new Workbook();
Worksheet sheet = workbook.Worksheets[0];
sheet.Cells.ImportDataTable(dt, true, 0, 0);
workbook.Save("EmployeeReport.xlsx");

Importing a DataTable this way reduces manual row-by-row mapping and keeps the export code concise.

Export Entity Framework results

For Entity Framework, select the fields needed in the report and materialize the query:

var employees = db.Employees
    .Select(x => new
    {
        x.EmployeeCode,
        x.EmployeeName,
        x.Salary,
        x.JoinDate
    })
    .ToList();

Pass the selected values to the worksheet as an object array:

sheet.Cells.ImportObjectArray(
    employees.Select(x => new object[]
    {
        x.EmployeeCode,
        x.EmployeeName,
        x.Salary,
        x.JoinDate
    }).ToArray(),
    1,
    0,
    false);

Apply formatting after importing

After import, apply number formats to the relevant columns and fit column widths to their contents:

Style salaryStyle = workbook.CreateStyle();
salaryStyle.NumberFormat = "₹#,##0.00";
sheet.Columns[2].ApplyStyle(salaryStyle);

Style dateStyle = workbook.CreateStyle();
dateStyle.NumberFormat = "dd-MMM-yyyy";
sheet.Columns[3].ApplyStyle(dateStyle);

sheet.AutoFitColumns();

Build a reusable Excel export service

In a larger application, place shared export logic in a reusable service rather than duplicating it across controllers:

public static byte[] ExportToExcel(DataTable dt)
{
    Workbook wb = new Workbook();
    Worksheet ws = wb.Worksheets[0];
    ws.Cells.ImportDataTable(dt, true, 0, 0);
    ws.AutoFitColumns();

    using (MemoryStream ms = new MemoryStream())
    {
        wb.Save(ms);
        return ms.ToArray();
    }
}

Call the service with report data and write the resulting bytes to a file or return them as a download:

DataTable dt = repository.GetReportData();
byte[] fileBytes = ExcelExporter.ExportToExcel(dt);
File.WriteAllBytes("Report.xlsx", fileBytes);

Recommended reporting flow

Keep data access, mapping, and file generation separate so each part can be maintained independently:

SQL Server → Stored Procedure → Repository Layer → DataTable / DTO Objects → Excel Export Service → ZetExcel Workbook → XLSX Download

Common formatting standards

  • varchar: text
  • int: #,##0
  • decimal: #,##0.00
  • money: ₹#,##0.00
  • datetime: dd-MMM-yyyy
  • percentage: 0.00%

Conclusion

ZetExcel can simplify Excel report generation in .NET applications by removing the dependency on Microsoft Excel while supporting workbook formatting and data imports. Importing DataTables or Entity Framework results lets you generate useful reports with less manual mapping. The same approach can be used for employee information, attendance, financial statements, CRM data, and operational dashboards.
