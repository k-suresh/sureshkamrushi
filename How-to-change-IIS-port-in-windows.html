How to Change the Port for a Website in IIS on Windows

Update a website's HTTP binding in Internet Information Services (IIS) Manager to resolve port conflicts or run the site on a different local port.

November 21, 2017

If Internet Information Services (IIS) and another local web server are competing for the same HTTP port, change the binding for the IIS website that needs a different port. For example, the default HTTP binding commonly uses port 80. The steps below update the binding for the Default Web Site; choose the specific site you intend to change.

Change the IIS website binding

  1. Open Internet Information Services (IIS) Manager from the Start menu.
  2. In the Connections pane, expand the server and select Sites, then choose the website you want to change, such as Default Web Site.
  3. In the Actions pane, select Bindings….
  4. Select the site's HTTP binding and choose Edit.
  5. Enter an unused port number in the Port field. Leave the IP address and host name unchanged unless you also intend to change which addresses or host names the binding serves.
  6. Select OK, close the bindings dialog, and restart the website if IIS prompts you or the binding change has not taken effect.

Open the site using its new port

Include the port number in the browser address. For example, if you changed the port to 8081, open http://localhost:8081/ on the IIS server. If accessing it from another computer, use the server's host name or IP address and confirm that the relevant firewall rules allow that traffic.

Check for port conflicts and binding overlaps

  • Choose a port that is not already in use by another application or website binding.
  • Check the binding's IP address, port, protocol, and host name if IIS reports a conflict or serves the wrong site.
  • Update bookmarks, local application settings, and development tools that still use the old URL.
  • For production sites, review firewall, proxy, and hosting configuration before changing a listening port.

Changing an IIS binding changes only that website's listener. It does not automatically change the port used by another server application. Make sure the new address is reachable only by the intended users and that any network changes follow your organization's policies.

In short: Select the IIS website, open Bindings…, edit its HTTP binding, set an available port, and browse to the site using http://localhost:PORT/.
